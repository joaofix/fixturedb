# Analysing the datasets

The datasets are two SQLite files: `db/a.db` (Dataset A) and `db/c.db`
(Dataset C). Each file has the same tables. See the
[database schema](../architecture/database-schema.md).

## Read one dataset

```python
import sqlite3
import pandas as pd

conn = sqlite3.connect("db/a.db")

summary = pd.read_sql("""
    SELECT COUNT(*) AS fixtures,
           ROUND(AVG(loc), 2) AS avg_loc,
           ROUND(AVG(cyclomatic_complexity), 2) AS avg_complexity,
           ROUND(AVG(comment_density), 3) AS avg_comment_density
    FROM fixtures
""", conn)
print(summary)
```

Agent counts, for Dataset A only:

```sql
SELECT agent_type, COUNT(DISTINCT commit_sha) AS commits, COUNT(*) AS fixtures
FROM fixtures
WHERE agent_type IS NOT NULL
GROUP BY agent_type
ORDER BY commits DESC;
```

Language mix of a dataset:

```sql
SELECT r.language, COUNT(*) AS fixtures
FROM fixtures f
JOIN repositories r ON f.repo_id = r.id
GROUP BY r.language
ORDER BY fixtures DESC;
```

## Compare the two datasets

The two databases cannot be joined. Load each one into pandas and concatenate them:

```python
import sqlite3
import pandas as pd

def load_fixtures(dataset: str) -> pd.DataFrame:
    """Return the fixtures of one dataset, with repository controls."""
    conn = sqlite3.connect(f"db/{dataset}.db")
    df = pd.read_sql("""
        SELECT f.*, r.language, r.domain, r.repo_age_years
        FROM fixtures f
        JOIN repositories r ON f.repo_id = r.id
    """, conn)
    df["dataset"] = dataset
    return df

combined = pd.concat([load_fixtures("a"), load_fixtures("c")], ignore_index=True)
```

**The paper tests repository means, not fixtures.** Each repository gives one
value: the mean of its fixtures. Then the two datasets are compared with a
Mann-Whitney U test. The `research_questions/` scripts do this. Use them for
any result you report.

A test on individual fixtures is useful for exploring the data. It is not the
paper's test, and its p-values are inflated, because fixtures in the same
repository are not independent.

## Control variables

Compare the two datasets on language, domain and repository age before you
compare anything else:

```python
balance = combined.groupby("dataset").agg(
    top_language=("language", lambda x: x.value_counts().index[0]),
    top_domain=("domain", lambda x: x.value_counts().index[0]),
    median_repo_age_years=("repo_age_years", "median"),
)
print(balance)
```

The balance report is generated by `python -m collection.research_questions.balance`.
The latest result is in `research_questions/balance.md`.

## What to report

1. Say that the comparison is cross-repository. The two datasets come from
   different repositories and different years. The design cannot separate
   agent authorship from repository effects.
2. Report the control-variable balance next to any comparison.
3. Describe agent detection as trailer and author based. See
   [agent detection](../architecture/agent-detection.md).
4. Take fixture counts from `datasets/{a,c}/summary.yaml`. Do not estimate them.
5. Say that Dataset C is from before 2021. Framework and practice changes between
   then and 2025 are a threat to validity.
